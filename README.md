# For Mey

A birthday card that opens into a scrapbook. One page, no build step.

- `index.html` holds everything: the words, the layout and the interactions.
- `photos/` and `assets/` hold the pictures, the video clip and the paper textures.
- `.github/workflows/pages.yml` publishes the site to GitHub Pages on every push to `main`.

To change the letter, open `index.html` and search for `ALLEN:`.
